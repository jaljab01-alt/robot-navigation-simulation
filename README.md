# AI Robot Navigation Simulation

## Requirements
- Python 3
- Tkinter (included with most Python installations)

## Run the simulation
```bash
python robot_simulation.py
```

Click **Start Robot** to watch the robot move from the green start square to the red goal square while avoiding black obstacles.

## Features
- Basic mobile robot model
- Simulated proximity sensor readings
- Dijkstra's shortest-path algorithm
- Obstacle avoidance
- Animated robot movement
